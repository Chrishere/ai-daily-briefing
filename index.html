Raschka详解Claude文本水印技术原理

来源：magazine.sebastianraschka.com · How Claude Watermarks AI-Generated Text（8 月 22 日）
总结：Sebastian Raschka 制作了一期 48 分钟的视频讲座（附文字稿），系统拆解 Anthropic 为 Claude 生成文本添加水印的技术原理。他解释水印并非作用于模型内部，而是发生在 token 采样阶段：Anthropic 用一把类似 API Key 的密钥，结合此前若干个 token 的上下文，共同推导出一个确定性的随机种子，从而让原本随机的采样过程变得可复现、可检测。由于只有 Anthropic 掌握这把密钥，检测水印需要依赖其未来提供的 API；而普通用户由于不知道具体是哪些位置被"做了手脚"，想要去除水印就必须编辑多处文本，容易连带损害内容质量。

But this random seed, instead of being like a number that is fixed based on, I don't know, someone writing down a fixed number, they're using a secret key that is essentially like an API key, a secret key, and from that key, together with the four previous words, they derive this random seed essentially."
