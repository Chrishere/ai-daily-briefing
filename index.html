总结：Sebastian Raschka 撰文回应"循环／递归深度 Transformer 会让模型隐藏真实思维链"的担忧。他以 GPT-6 Astra 为例指出，更强模型给出更短的推理过程，更可能是因为模型更少犯错、更少需要回溯，而非刻意掩盖推理步骤；他类比 GPT 5.6 家族中 Sol 比更小的 Luna 模型用更少 token 却达到同等表现，说明没人因此认为 Sol 的可解释性更差。他认为，能力越强的模型往往推理越"高效"（即 token 更少），这是效率提升的自然结果，而不是架构上刻意设计的欺骗。

"Using fewer tokens could just mean that the model is more capable and makes fewer mistakes, uses less backtracking, and so on. I don't think that anyone has strong concerns that GPT 5.6 Sol is so much less interpretable than the smaller GPT 5.6 Luna model, which uses many more tokens for the same task performance."
